Fixes
- Canonicalizes YouTube watch URLs and strips playlist/radio tracking parameters before yt-dlp.
- Canonicalizes Spotify track URLs and strips share tracking parameters.
- Removes the old hidden Spotify -> YouTube search fallback that caused Spotify links to report YouTube anti-bot errors.
- Spotify now reports a provider-specific status instead of pretending it can fetch full-track audio.
- Existing YouTube EJS/Node runtime support remains enabled.

Important
- YouTube on datacenter IPs remains best-effort. A real YouTube anti-bot challenge cannot be guaranteed away by URL normalization.
- Spotify official URLs provide metadata, not a downloadable full-track file to this resolver.

V1.0.4 TikTok update:
- TikTok public video/share URLs are recognized as provider=tiktok.
- TikTok media is resolved with yt-dlp and converted to MP3 using the existing FFmpeg pipeline.
- SoundCloud behavior is unchanged.
- Spotify remains metadata-only and YouTube remains best-effort on datacenter IPs.
